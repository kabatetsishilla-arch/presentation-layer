Local area network
1. Photo Created

“This is where the user creates or takes a photo. The photo is the original data that we want to send through the network.”

Simple example: I take a picture using my phone.

2. Translate / Format

“Here, the photo is changed into a format that the computer or network can understand and use. This makes sure the data is in the correct format.”

Simple example: A photo can be converted into a format such as JPG or PNG.

3. Encrypt

“Here, the photo is protected by converting it into a secret form. This prevents unauthorized people from easily understanding or accessing the information.”

Simple example: Before sending the photo, it is encrypted so that only the intended receiver can read or use it.

Easy way to present all three

“First, the photo is created. Second, the photo is translated into the required format. Third, the photo is encrypted for security. After that, it can be compressed and sent through the network.”
